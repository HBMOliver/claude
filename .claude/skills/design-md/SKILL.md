# design-md

A collection of DESIGN.md files (from VoltAgent/awesome-design-md, MIT). Each one describes a site's visual language: colour tokens, type scale, spacing, radii, components and do/don't rules, written for AI agents to build from.

## How to use

1. Pick the brand: `brands/<name>/DESIGN.md`. If the user names a brand that isn't listed, offer the closest match. If they only describe a feel ("dark developer tool", "luxury car"), suggest 2-3 fitting brands.
2. Read the whole DESIGN.md before writing any UI, and follow its tokens and rules exactly rather than approximating.
3. To give the user's own project a design system, copy the chosen file to `DESIGN.md` in their project root and adapt names and colours to their brand if asked.

## Limits

These are style references. Build original pages for the user's own brand in that style. Do not reproduce the company's logo, name or trademarks, or make a page that could pass as the real company's site.
